Brackenford — models wanted for Chapter 2, The Waking
For generating in Tripo (or any text-to-3D tool) and dropping into this folder.

HOW TO MAKE THEM
Paste a prompt below into Tripo's text-to-3D. Choose a low-poly or stylised setting if offered, and the lowest face count that still reads well.
Export as GLB (binary glTF) with the texture embedded. Save it in this folder under the file name given.
Aim for under 5,000 triangles per creature and under 10,000 for the stall. Keep each file under 3 MB.
If the tool offers rigging or animation, skip it for now: the game moves and bends the models itself.
Pose: standing naturally on flat ground, facing forward. No base or plinth. One object per file.

THE LOOK
Flat-shaded low-poly, soft warm colours, no realism, no fur detail. These are spirits made of leaves and light, not animals:
friendly, a little glowing, nothing that reads as prey or as a trophy.

WHAT HAPPENS WITHOUT THEM
The game is being built with simple shapes made in code standing in for every item above, so nothing waits on this list.
When a file with one of these names appears in this folder, it can replace its stand-in.
Loading GLB files needs one small extra library added to the game, which has not been added yet.

MAKING THEM AUTOMATICALLY
tools/make-assets.mjs does the whole chain for the same list (kept in asset-list.json): a concept picture from OpenAI's image model, then a 3D model of that picture from Tripo, saved here as a GLB.
It needs your own keys, set in the terminal before running it and never stored by the script: TRIPO_API_KEY, and OPENAI_API_KEY for the picture step.
  node tools/make-assets.mjs --plan            shows what it would make and costs nothing
  node tools/make-assets.mjs --images-only     makes only the pictures, into assets/concepts, so you can look before paying for models
  node tools/make-assets.mjs --only sun-bird   makes one model
  node tools/make-assets.mjs                   makes everything not yet made
Both services charge the account each key belongs to. The script has been checked only as far as its plan and its refusals without keys; it has never been run against either service.

## 2. Difficulty Curve & Recommended Order Inside Each Place

Regrouping breaks `Stages.md`'s alternating ring/shade rhythm (after `First shade`, players play 6–7 ring-only stages before Tier 3 shades—flag to developer as a pacing trade-off), and ChatGPT's raw assignment lets players hit `Crossing pair` and `The gauntlet` in Quarry before Pier teaches wind or single sliders. Applying the two moves above (`The gauntlet → Stormcrest`, swapping `Sliding mark ↔ Three ranges`) fixes every dependency:

| Place | Recommended Release Order | Held-Back Order (Post-Clear) |
|---|---|---|
| **1. Brambleford** | First marks → Stepping back → The drop → First shade | Small bull → The long lane |
| **2A. Reedwater Pier** | A breeze → Crosswind → Three ranges | Slide and breeze → Long wind |
| **2B. Flint Quarry** | Pop-ups → Sliding mark → Crossing pair | Quick marks → Far and small |
| **3A. Alderwood** | The warren → Horns in the grass → Creepers | Bolt |
| **3B. Bellward Village** | On the post → Flush | Flight line |
| **4. Stormcrest** | The gauntlet → Blighted meadow | Gusts → Storm lane → Far slider → Master of the line |

## 3. Exact Travel & Unlock Logic

- **Stage clear:** `stars[stageId] >= 1`. **No 2- or 3-star / score gates** on main progression (medals remain mastery rewards; held-back stages in a place unlock when that place is cleared).
- **In-place progression:** First release stage of an unlocked place is open immediately; `stage[k]` opens when `stars[stage[k-1]] >= 1`.
- **Place clear:** `placeCleared(P) := P.releaseStages.every(id => stars[id] >= 1)`.
- **Place unlock tree:**
  - `Brambleford`: always `true`.
  - `Pier` & `Quarry`: `placeCleared(Brambleford)`.
  - `Alderwood` & `Bellward`: `placeCleared(Pier) && placeCleared(Quarry)` *(fallback if playtesting shows stalls: unlock Tier 3 on `placeCleared(Pier) || placeCleared(Quarry)`).*
  - `Stormcrest`: `placeCleared(Alderwood) && placeCleared(Bellward)`.
- **Travel:** Via `MAP` sign/button at any stance or results screen → select unlocked place → `0.5 s` VR fade-to-dark straight to that place's fixed stance.
- **Save schema:** Key `best[stageId]` and `stars[stageId]` by **stable stage ID** (not release index), plus `currentPlace` and `lastStageByPlace[placeId]`.

## 6. What Is Wrong or Missing (Plainly)

1. **Tier 2 tutorial inversions & thin finale:** As written, Quarry has `The gauntlet` and `Crossing pair` before Pier teaches wind/sliders, and Stormcrest has only 1 release stage. Apply the 2 stage moves in §1–2.
2. **Stormcrest blue-hour shade visibility:** Dark-plum shades vanish against plum-grey rock; mandate pale grass/stone on the `12–30 m` saddle.
3. **Alderwood corridor trunks:** Cannot sit inside `10–32 m, ±7 m` without breaking `Creepers` and `Bolt` straight-line paths.
4. **Flint Quarry deep-bowl angle:** `12–15 m` targets break seated comfort unless placed on `-2.0 m` upper benches.
5. **Map vs rules & naming:** `world-map-v1.jpg` draws a direct dotted shortcut from Brambleford to the centre hub (remove or dim it so it matches the unlock tree), and **"Brambleford"** is too close to **"Brackenford"** (rename Place 1, e.g., **Meadowgate** or **Willowford Range**).
6. **Missing specs & release scope:** No mention yet of (a) how the VR/desktop map UI works, (b) whether the Market Stall (`H6`) stays only at Place 1 or appears on the map, (c) refactoring saves from stage index to stable stage ID, and (d) scope: 6 environments is post-launch work—Trials release still ships on Place 1 first unless the developer explicitly changes the launch scope.
